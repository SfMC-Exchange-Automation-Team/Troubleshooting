PREPARE MISSING INSTALLATION FILES
  Get does not need payload files. Set does.
  No arguments shows usage/examples and exits 0: no prompt, download,
  elevation or file writes:
    .\Install-KoreanRules.ps1

  If payload\ko.token.rule.bin or payload\ko.complex.rule.bin is missing,
  choose ONE source in elevated Windows PowerShell:
    $build = .\Install-KoreanRules.ps1 -Download
    # OR an existing EXE, or folder directly containing the EXE/rule BINs:
    $build = .\Install-KoreanRules.ps1 'C:\Temp\SQLEXPR_x64_ENU.exe'
    $build = .\Install-KoreanRules.ps1 'C:\Temp\VerifiedKoreanRules'
    $build | Select-Object ExpandedPackage, PayloadDirectory

  First argument is INPUT (SqlPackagePath, alias Path), not a destination.
  Optional second argument is a NEW output directory:
    $build = .\Install-KoreanRules.ps1 '.\Media\SQLEXPR_x64_ENU.exe' 'C:\Temp\PreparedRules'
  To select a download destination:
    $build = .\Install-KoreanRules.ps1 -Download -OutputDirectory 'C:\Temp\PreparedDownload'
  Omit output for a unique child of C:\Temp\KoreanRules-Ready.

  Folders are not searched recursively. Select the folder directly containing
  SQLEXPR_x64_ENU.exe or ko.token.rule.bin/ko.complex.rule.bin. EXE plus either
  BIN is ambiguous: select the exact EXE or use -RuleSourceDirectory.
  A partial rule pair lists the missing file; no input error autodownloads.
  Quote paths with spaces once. Paired double/single quotes inside a pasted
  path string are accepted; paths/relative paths are literal, never commands.

  Download is an explicit approximately 749 MB Microsoft media download.
  Install prepares verified files; it does not install SQL or modify Exchange.
  Invalid existing inputs are rejected before work/output creation or execution.
  Media mismatch shows found/required bytes, SHA256 and version. Obtain a fresh
  complete Microsoft copy; smaller files can be incomplete downloads. Do not
  bypass hashes or the required signature, or escalate routine input errors.
  Downloads use SQLEXPR_x64_ENU.partial.exe until identity/signature pass.
  Failures retain available diagnostics, report once and exit 1 by default;
  use -ErrorAction Stop for a catchable automation exception.
  It does not populate this source folder's payload directory. Use the returned
  PayloadDirectory, or the generated runtime under ExpandedPackage.

PREVIEW REMEDIATION
  With a verified payload beside the scripts:
    .\Set-KoreanRulesState.ps1 -WhatIf
    # OR an explicit target:
    .\Set-KoreanRulesState.ps1 EX01 -WhatIf

  Or, using the preparation result:
    .\Set-KoreanRulesState.ps1 -PayloadDirectory $build.PayloadDirectory -WhatIf

  Set without WhatIf is modifying. Never overwrite existing rules or reapply
  blindly. Restarts require explicit RestartSearch and MaintenanceWindowApproved.
  Expected skips: leave unchanged; review actual build, prior receipt or partial
  pair, not routine Support escalation. Partial modifying failures, abandoned
  operations, unstable service/ContentEngine or exceptional rollback still
  warrant Support. Rollback retains its Support-approval requirement.
